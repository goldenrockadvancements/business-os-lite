# Business OS — Lite (free)

A free Obsidian vault to run a small service business: clients, pipeline and projects, with one Home page that shows what needs you today. No plugins.

## Get started
1. Download this repo (**Code -> Download ZIP**) or clone it.
2. In Obsidian: **Open folder as vault** and pick this folder.
3. Start with `Home.md`.

## Free lite vs. the full $27 edition
This repo is the free **lite** edition. The full edition adds: full clients / pipeline / projects / tasks / invoices / expenses, **27** views and **10** written procedures.
